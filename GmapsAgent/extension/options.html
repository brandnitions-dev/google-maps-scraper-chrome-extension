Enrich API (local or VPS)

Same values as the sidebar Remote enrich API block. Base URL must not end with a slash. For VPS Docker deploy, API is usually port 31876; admin UI is 31877 (see GmapsAgent/deploy/vps/README.md).

Email enricher folder (local Copy path)

Paste the full absolute path to your EmailEnricher directory (the folder that contains start_enrich_server.bat). This is only used by the sidebar Copy path buttons. Chrome cannot open File Explorer for you.
